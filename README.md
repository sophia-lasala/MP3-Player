# Raspberry Pi-Based MP3 Player

A portable MP3 Player designed and created using a Raspberry Pi computer. 

## Current Progress 

SolidWorks is currently being used to create a casing that will be adjusted to fit the internal components later on in the process. 

## Next Steps 

After completing the casing, the next step would be to create the supply list and begin working on the user-interface and back-end code for the project. 

## Planned Features 
### Hardware 
- Focus on drop resistance and sturdiness in design and material
- Long battery life
- Headphone Jack and Bluetooth support
- Aiming for approximately 5.83 x 3.54 x 1.26 in measurements

### Software 
- Display metadata such as album covers, artists, and genre 
- Automatically organize songs based on genres and artists
- Allow for shuffled albums and playlists
- Allow to shift between light and dark mode

Edits to design aspects to be made
