# Portable MP3 Player

A portable MP3 Player designed and created using a Raspberry Pi computer. 

## Current Progress 

SolidWorks is currently being used to develop the initial enclosure for the MP3 player.

The design is being created with the internal hardware in mind, with the goal of producing a compact enclosure that provides adequate protection for the electronics while maintaining access to the necessary controls, ports, and other components.

The current target dimensions are approximately:

5.83 × 3.54 × 1.26 inches

The design is expected to change as the internal hardware is selected and tested.
## Next Steps 

The next stage of development will focus on determining the hardware required for the completed device.

Planned steps include:

1. Finalize the initial enclosure design
2. Determine the required internal components
3. Create a complete hardware and power-supply list
4. Adjust the enclosure to accommodate the selected components
5. Begin development of the user interface
6. Develop the backend responsible for managing the music library
7. Integrate the hardware and software into the completed device

## Planned Features 
### Hardware 
- Durable enclosure designed with drop resistance in mind
- Compact portable form factor
- Long battery life
- 3.5 mm headphone jack
- Bluetooth audio support
- Physical controls for interacting with the device
- Custom enclosure designed around the selected internal components

### Software 
- Display album artwork and music metadata
- Display artist and genre information
- Organize music by artist and genre
- Shuffle albums and playlists
- Create and manage playlists
- Light and dark interface modes
- Music playback controls

Edits to design elements to be made.
